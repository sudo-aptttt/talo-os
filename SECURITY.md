## 🔒 Signaler une Vulnérabilité

Si vous découvrez une faille de sécurité ou une vulnérabilité dans Talo OS, **merci de ne pas ouvrir d'issue publique sur GitHub**.

Veuillez signaler le problème de manière responsable et confidentielle :
* **Par e-mail** : `dorian.talon.13@gmail.com`
* **Sujet** : `[VULNERABILITÉ] Talo OS - <Description courte>`

### Informations utiles à inclure :
1. Une description précise du comportement ou de la faille constatée.
2. Les étapes détaillées permettant de reproduire le problème.
3. L'environnement de test (modèle de l'appareil, version Android TV / Google TV).
4. Le niveau d'impact potentiel estimé.

Nous nous engageons à accuser réception de votre signalement dans un délai rapide, à évaluer l'impact et à déployer un correctif de sécurité dans une version corrective.
